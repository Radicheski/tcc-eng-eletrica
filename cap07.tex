\chapter{Contribuição Esperada para a Ênfase e Importância para a Formação do Autor} \label{cha:contribuicao}

Este projeto permite a aplicação de conceitos de eletrônica de potência, medição
de grandezas elétricas e sistemas embarcados. Além disso, contribui para a formação
acadêmica ao proporcionar experiência em desenvolvimento de hardware e software
para sistemas de aquisição de dados.
